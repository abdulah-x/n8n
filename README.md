# n8n Automation Workflows

A collection of n8n workflow automation templates for various tasks including AI integration, Discord moderation, and portfolio tracking.

## 📋 Workflows

### 1. Discord AI Auto-Moderator
Automated Discord moderation system that runs every 10 minutes to monitor and moderate server messages using AI.

### 2. Gemini-Bot
AI-powered chatbot using Google's Gemini model with conversational capabilities through n8n's LangChain integration.

### 3. Portfolio Tracker
Automated portfolio tracking system that runs daily at 12 AM, integrating with Google Sheets for data management.

### 4. Simple Mail Send
Basic email automation workflow for sending emails through n8n.

### 5. The Oracle
Custom AI workflow for specialized tasks and predictions.

## 🚀 Usage

1. Import any `.json` file into your n8n instance
2. Configure credentials and API keys as needed
3. Activate the workflow

## 📦 Requirements

- n8n (self-hosted or cloud)
- Required API keys/credentials based on the workflow you choose

## 📝 Notes

These workflows are ready-to-use templates that can be customized based on your specific needs.
